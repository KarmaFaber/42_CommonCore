About Webserv 2026

The Heart of 42 Madrid


Webserv is not just a project; it is the cornerstone of the network and low-level programming module at 42 Madrid. This HTTP/1.1 server is built from scratch in C++, handling simultaneous connections, request parsing, file management, and error handling.


It represents our dedication to understanding how the internet works at a fundamental level.


The primary objective is to demonstrate an understanding of network protocols and the implementation of a robust and efficient server capable of serving static content and handling complex POST forms.

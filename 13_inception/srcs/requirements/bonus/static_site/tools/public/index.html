About Inception 2026

The Heart of 42 Madrid



The goal of this project is to broaden your knowledge of system administration by using Docker. You will virtualize several Docker images, creating a complete infrastructure composed of multiple services that must run in separate containers, communicate through a private network, and persist data using volumes.
